Camera Deck 0.4.0 — новый чёрно-жёлтый интерфейс Android и Windows.

- Большие видоискатели, компактные жёлтые ячейки ISO / выдержки / формата, отдельная красная индикация REC. Показания берутся из состояния камеры, декоративных индикаторов батареи или уровня звука нет.
- Windows: быстрый переход к настройкам нажатием на ячейки, компактные группы и панель управления. Кнопка обновления Android появляется, когда обновление доступно.
- Android: экран камеры вместо длинного списка; панели подключения, съёмки и питания. Добавлены местные кнопки фото/видео, записи и настроек ISO/выдержки/фокуса, разрешения/FPS и формата фото.
- Локальный VIEW на телефоне выключен по умолчанию. Работа в фоне и ECO сохранены; экран принудительно не удерживается включённым. Фактическое потребление батареи ещё не измерено.
- Собственный дизайн без логотипов или ресурсов Sony. Скриншоты Windows в README сняты с работающего TLS-стенда; это симуляторы, не реальные камеры. Android-интерфейс на физическом телефоне пока не проверен.

Публичный репозиторий: https://github.com/prostoodin1/Camera-Deck.

Публичные подписанные обновления больше не требуют GitHub-токена. Прежние ключи подписи APK и обновлений сохранены. Пользователям 0.3.0 и старше нужно один раз скачать 0.3.1 из нового репозитория; далее обновления идут отсюда автоматически. APK устанавливается поверх предыдущего, без удаления приложения.

Скриншоты настоящего интерфейса на функциональном TLS-стенде находятся в README и docs/screenshots; источники явно помечены как симуляторы, реальные телефоны ещё не проверены. Исправлен контраст вкладок настроек.

- MP4 со звуком AAC-LC, 48 кГц mono, по умолчанию. После обновления остановите и включите камеру на телефоне, разрешив микрофон.
- Живое прослушивание: «Слушать микрофон телефона» на Windows. Один микрофон обслуживает прослушивание и запись; их включатели независимы.
- Переключатель «Фото / Видео» в окне каждой камеры.
- В «Настройки»: разрешение и целевой FPS записи, формат и размер фото. Доступные комбинации берутся из Camera2 и видеокодека; предел списка — 4K/60, без высокоскоростных сессий. Эти режимы на телефонах ещё не проверены.
- JPEG, PNG, WebP и RAW DNG при поддержке камеры. PNG/WebP конвертируются из обработанного JPEG; DNG использует настоящий RAW и соответствующие метаданные. Предел фото — 24 Мп для контроля памяти.
- Смена режима, разрешения, FPS и формата доступна после остановки записи. Фото во время видео не поддерживается.
- Экономный фон и подписанные обновления сохранены. Сворачивание Windows прекращает просмотр/прослушивание, но не запись. Без записи/слушателей микрофон останавливается.

В глубоком энергосбережении Android может задерживать сетевые подключения. Автоматического обхода системной оптимизации батареи нет. Мгновенное пробуждение в любых условиях не обещается.

Включены поиск телефонов в LAN, подключение по PIN с проверкой TLS-отпечатка, несколько окон и группы, фото, локальная MP4-запись, доступные ручные настройки ISO/выдержки/фокуса и скачивание оригиналов.

Windows автоматически проверяет публичные релизы и скачивает новую версию; установка выполняется при подтверждённом перезапуске. APK передаётся с Windows на телефон, проверяет подпись манифеста, SHA-256 и сертификат приложения, затем устанавливается через подтверждение Android.

Разрешение и FPS в настройках относятся к оригиналу записи. Живой предпросмотр пока JPEG около 640px до 5 кадров/с в Eco / 10 кадров/с в обычном режиме. Звук передаётся отдельным PCM-потоком; синхронизация губ с живым изображением не реализована. MP4 использует общий источник времени и аппаратные аудиометки, когда доступны; точность синхронизации не измерена.

Проверки: сборки APK/EXE, Android Lint, 26 проверок Windows/протокола, 3 Android JVM-теста выбора режимов и TLS-стенд с передачей JPEG/команд/тестового фото. Физические телефоны не подключены: воспроизведение микрофона, синхронизация, декодирование MP4, RAW, FPS, нагрев и батарея требуют проверки на устройствах. Обновите оба приложения. Для обновления удалять приложение не нужно; перед удалением скачайте сохранённые оригиналы.

Скачайте APK на каждый телефон и EXE на Windows. Инструкция находится в README.md и ZIP исходников. Для обновления удалять приложение не нужно.
