# Camera Deck 0.11.5 · постоянный клиент

Исправлен запуск системного установщика из Windows EXE: системный путь DLL, независимое окружение PyInstaller и корректные потоки ввода/вывода для фонового процесса. Самопроверка EXE теперь действительно запускает установщик и ждёт контрольный файл; без этого публикация блокируется. Предыдущие 0.11.1 и 0.11.3 — устаревшие тестовые выпуски; для перехода с них запустите установщик этой версии поверх существующего профиля.

Одна установленная программа на Windows и одна на Android. Следующие версии заменяют эту же установку через подписанные патчи; настройки, доверенные подключения и записи сохраняются.

- Windows: CameraDeck-Setup.exe устанавливает клиент в профиль пользователя и создаёт один ярлык Camera Deck. Автопроверка, проверка подписи и хеша, установка при простое, резерв предыдущего EXE и возврат при неудачном запуске.
- Android: CameraDeck-Android.apk — release-сборка без debug-доступа, пакет .aurora. Подписана тем же сертификатом, что тестовая Slate 0.10.0. Устанавливать поверх неё без удаления. Для старых 0.9 совместимость подписи не подтверждена.
- Один раз разрешите Camera Deck устанавливать обновления в системных настройках Android. Автоустановка запрашивается стандартным PackageInstaller; если ОС требует подтверждение, будет уведомление.
- Фоновые проверки Android планирует ОС каждые 6 часов при доступе к сети без тарификации; в открытом приложении — каждые 15 минут. Windows также доставляет подписанный APK подключённым обновлённым телефонам через USB/Wi-Fi.
- Во время записи, фотографии, обработки копий и активного использования камеры Android установка откладывается. Остановите съёмку и выключите камеру для установки. После замены APK Android может потребовать снова включить камеру вручную.

Изображение и интерфейс: EV по реальному шагу сенсора, AE-L, замер света, доступные балансы белого/антимерцание/аппаратные фильтры, контраст и гамма, логарифмический ISO, плавные метки нескольких лиц, выбор лица/глаза, уголки/овал, компактный режим. Поддержка зависит от объектива; кружки глаз не гарантируют резкость глаза.

Галерея по умолчанию: DCIM/Camera Deck. Приватный исходник остаётся резервной копией. Программное размытие по маске человека выключено по умолчанию: создаёт отдельную JPEG/MP4-копию после выключения камеры, до 1920 px по длинной стороне, сохраняет аудиодорожку. Исходная запись не перезаписывается. Группы, волосы, движение, GPU-совместимость и фактическая синхронизация звука требуют проверки на телефонах.

Это предварительный релиз. Сборка, тесты и скриншоты стенда не подтверждают стабильность всех устройств. Независимая проверка длительной записи, нагрева и реальной установки Android-патча необходима перед важной съёмкой.

Известное наблюдение предыдущего прогона SM-S908B: при выборе 8/10 fps получалось около 15 fps. Исправление этого режима новой сборкой пока не подтверждено; для проверки новой версии используйте поддерживаемые 24/30 fps. Скриншоты нового интерфейса: docs/screenshots/client/.
