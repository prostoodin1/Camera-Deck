# Проверка Windows-дистрибутива

0.12.0 снят с публикации: Defender обнаруживает CameraDeck-Setup.exe как Trojan:Win32/Sabsik.TE.A!ml. Не доказано, что это ложное срабатывание. Старые файлы сохранены в закрытом черновике для анализа; они не выдаются публичным каналом обновлений.

Для 0.12.2 окружение собрано отдельно из PyPI; версии runtime и упаковщика закреплены, аудит зависимостей и тесты запускаются до упаковки. Добавлены штатные сведения о продукте в EXE. Упаковщик использует штатный bootloader, без UPX, обфускации, модификации антивируса или исключений. Детерминированные seed/timestamp облегчают сравнение, но не обещают полную побитовую воспроизводимость между разными машинами.

CI сканирует конечный EXE через MpCmdRun custom scan с DisableRemediation: этот режим игнорирует исключения, выводит обнаружения и не предпринимает действий по их устранению. Он не отключает защиту в реальном времени. Успех требует кода 0 и сохранения SHA-256 файла. Проверяется доступность Defender и возраст базы до 48 часов. Публикация требует совпадения EXE, commit, версий сканера и отчёта моложе 24 часов. Нет отчёта — нет публикации. CI оставляет черновик; тот же загруженный файл дополнительно сканируется локально перед открытием релиза.

Подпись манифеста обновлений подтверждает происхождение файла из канала проекта, но не является антивирусной проверкой и не заменяет Authenticode. Доверенного сертификата издателя Windows у проекта сейчас нет. Положительный результат Defender относится к указанным базам и времени; McAfee/WebAdvisor или SmartScreen могут вынести иной вердикт. Снятие обнаружения старого файла возможно через проверку у производителя антивируса; такой ответ пока не получен.

Официальный метод сканирования: https://learn.microsoft.com/en-us/defender-endpoint/command-line-arguments-microsoft-defender-antivirus
